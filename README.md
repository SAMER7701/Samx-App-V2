\# SAMX — نظام إدارة مبيعات الفروع

\## ✨ المميزات



\- ✅ \*\*ثنائي اللغة:\*\* عربي (RTL) + إنجليزي (LTR)

\- ✅ \*\*PWA + Offline-First:\*\* يعمل بدون إنترنت

\- ✅ \*\*White-Label:\*\* تخصيص كامل للهوية (شعار + اسم + ألوان)

\- ✅ \*\*تصدير:\*\* PDF + Excel + CSV

\- ✅ \*\*معالج إعداد أولي:\*\* Setup Wizard (5 خطوات)

\- ✅ \*\*إدارة:\*\* الفروع + الموظفين + المستخدمين

\- ✅ \*\*تقارير:\*\* يومية + شهرية + مقارنة سنوية (YoY)

\- ✅ \*\*مشاركة:\*\* بطاقة ملخص يومية كصورة

\- ✅ \*\*مؤشرات:\*\* UPT + ATV + نسبة التحقيق

\## 🛠️ التقنيات المستخدمة



\- \*\*Vue 3\*\* — إطار العمل الأساسي
